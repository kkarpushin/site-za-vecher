# Шаг 4 · Фото

Генератор — только после списка, цены и «да». Людей из генератора не выдавать за клиентов.

## Метапромптинг для фото

```text
Создай 4 промпта для генератора изображений:
- 2 промпта по моей идее
- 2 промпта по твоей собственной идее

Контекст: [ОПИСАНИЕ ПРОДУКТА/УСЛУГИ]
Стиль: гиперреализм, 4K, профессиональная фотография
Назначение: Hero section лендинга

Максимально продающее визуальное решение для этой услуги.
```

## Фото через коннектор

```text
Сделай фото для моего сайта через подключённый генератор картинок.

1. Найди места, где не хватает фото или стоит подпись «Фото: …». Для каждого напиши: блок, что в кадре, формат — 16:9 для компьютера или 9:16 для телефона.
2. На первом экране главный объект справа, слева место под текст. Для телефона — отдельный вертикальный кадр, объект по центру.
3. Напиши промпты для генератора. Стиль: [СТИЛЬ, НАПРИМЕР «ЕСТЕСТВЕННЫЙ СВЕТ, ЖИВАЯ СЦЕНА, БЕЗ СТОКОВОГО ГЛЯНЦА»].
4. Покажи список, промпты и сколько кредитов это стоит. Дождись моего «да». Всего не больше [ЧИСЛО] картинок.
5. После «да» сгенерируй, сохрани в site/public/images/, вставь на страницу и посмотри результат в превью на 375 и 1440 px.

Людей для отзывов, «до и после» и блока команды не генерируй: там только настоящие фото. Если генератор не подключён — скажи мне и просто дай промпты.
```
