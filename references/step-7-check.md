# Шаг 7 · Проверка глазами клиента

## Текст без ИИ-штампов

```text
Проверь тексты на моём сайте на ИИ-штампы.

Ищи шесть примет:
1. Пустые слова: «уникальный», «инновационный», «лучший», «высококачественный», «надёжный партнёр», «индивидуальный подход».
2. Пафос: «в современном мире», «откройте для себя», «погрузитесь», «раскройте потенциал».
3. Шаблон «не просто X, а Y» и «это не курс — это…».
4. Тройки ради ритма: «быстро, качественно, недорого».
5. Канцелярит: «осуществляем», «является», «данный».
6. Цифры и обещания без доказательств: «1000+ довольных клиентов», «гарантия 100%».

Вместо прилагательного — факт: что получит человек, сколько, когда, как это проверить. Факта нет — ставь {ЗАПОЛНИТЬ}.
Кнопки, подписи и подсказки исправь сам. Тексты оффера не меняй: покажи таблицу «было → стало» и дождись моего «да».
```

## Аудит перед публикацией

```text
Проведи полный аудит моего лендинга перед публикацией.
Проверь:
1. Все ли кнопки и ссылки работают (нет ли # заглушек)
2. Нет ли Lorem ipsum и placeholder-текста
3. Есть ли CTA на каждом экране при прокрутке
4. Корректна ли мобильная версия (375px)
5. Оптимизированы ли изображения
6. Нет ли ошибок в консоли
7. Есть ли у каждого движения задача, стоит ли сайт на месте при «уменьшить движение», весит ли каждое видео меньше 25 МБ
8. Собирается ли сайт без ошибок (npm run build) и есть ли текст страницы в HTML — виден без JavaScript
9. Есть ли title, описание и картинка-превью для соцсетей и мессенджеров (Open Graph), значок сайта
Составь список найденных проблем и исправь все критичные.
```

## Доводка дизайна скиллом

```text
Используй скилл redesign-existing-projects (плагин taste-skill).
Проверь мой сайт в папке site/ по чек-листу скилла. Сначала выпиши список проблем по разделам, потом исправляй по порядку: шрифт, цвета, кнопки, сетка и отступы. Стек не меняй. Порядок блоков, тексты оффера и надписи на кнопках без моего согласия не меняй. Правила сайта — в CLAUDE.md.
```
