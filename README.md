# Сайт за вечер — скилл для Claude Code

Скилл курса AI-Ковчег, урок 06 «Сайт за вечер». Проводит по маршруту урока от текстового прототипа до сайта в интернете: Claude идёт по восьми шагам и останавливается там, где нужно ваше «да».

| Шаг | Что получается |
|---|---|
| 1. Основа | папка проекта и правила сайта в CLAUDE.md |
| 2. Интерактив | калькулятор или квиз под главный вопрос клиента |
| 3. Дизайн | сайт по референсам, цикл проверки, DESIGN.md |
| 4. Фото | свои кадры из генератора |
| 5. Движение | живой первый экран и отклики |
| 6. Кнопки | Telegram и оплата |
| 7. Проверка | текст без штампов, телефон, аудит |
| 8. Публикация | ссылка на Cloudflare Pages |

Стек: Next.js, React, TypeScript и Tailwind со статической выгрузкой — текст страницы лежит в готовом HTML.

## Как поставить

Отправьте в Claude Code:

```text
Поставь мне скилл «Сайт за вечер» из github.com/kkarpushin/site-za-vecher: файлы репозитория должны лежать в папке ~/.claude/skills/site-za-vecher (на Windows — .claude\skills\site-za-vecher в моей домашней папке). Если git на компьютере нет — скачай архив репозитория и распакуй туда же. Когда закончишь, скажи, что нужно начать новую сессию, чтобы скилл подхватился.
```

## Как запустить

В папке проекта с `landing/prototype.md`, `dna/dna.md` и `offer/offer.md`:

```text
Примени скилл site-za-vecher: собери сайт по прототипу из landing/prototype.md, ДНК клиента и офферу. Иди по шагам и останавливайся там, где скилл просит моего «да».
```

Файлов нет — Claude спросит о продукте и сам соберёт короткий прототип.

## Файлы

- `SKILL.md` — маршрут из восьми шагов.
- `references/rules.md` — правила сайта для CLAUDE.md.
- `references/step-*.md` — промпты урока по шагам; `references/quiz.md` — квиз-воронка со скиллом quiz-funnel.
